# 📓 iNotebook - Your notes secured in the cloud

iNotebook is a full-stack web application that allows users to securely create, read, update, and delete their personal notes. Built with modern web technologies, it ensures that your data is safely stored in the cloud and accessible only to you.

## ✨ Features
* **User Authentication:** Secure signup and login using JWT (JSON Web Tokens) and bcrypt password hashing.
* **CRUD Operations:** Easily create, view, edit, and delete your personal notes.
* **Real-Time Search:** Instantly filter your notes by title or tag.
* **Responsive UI:** A clean, modern interface built with React and customized Bootstrap 5.
* **Data Security:** Notes are tied exclusively to the authenticated user's account in the database.

## 🛠️ Tech Stack
* **Frontend:** React.js, React Router, Bootstrap 5, Context API
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Authentication:** JSON Web Tokens (JWT), bcryptjs
